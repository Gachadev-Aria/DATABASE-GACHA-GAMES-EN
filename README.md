# Database Gacha Games FR

## Description: 
Un logiciel permettant de stocker les OC des jeux:
- Gache Club
- Gacha Plus
- Gacha Life 2
- Gacha Nebula v1.6

Le projet a commencé le 22/08/2026 et il se basait sur un projet existant de mon ordinateur.
